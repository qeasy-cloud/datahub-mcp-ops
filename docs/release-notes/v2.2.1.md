- 服务端 capability `2026-11-11`：60 工具（3 meta + 57 业务，含 `strategy.patch` / `strategy.delete`）。
- 服务端尚未发布该能力时：`strategy.patch`/`strategy.delete` 不可用；旧服务端回退到

  发布后由 `dh.py manifest` 重新生成，CI 严格模式随后去掉 `--allow-stale-manifest`。
