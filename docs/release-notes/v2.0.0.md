## v2.0.0 — 2026-10-28

**Capability baseline**: `datahub-mcp 0.1.0` / `x-capability-version 2026-10-28` / 46 tools

### Highlights

- **Daemon-free debug loop** — `dispatch → read job → consume → patch params → re-run`, documented end to end
- **7 new tools covered** — `strategy.queue.job.get` / `.run` / `.update`, `strategy.log.search`,
  `script.validate`, `asset.connector.list` / `.get`
- **Platform mechanics distilled into the repo** — metadata layers, value evaluation, parsers,
  runtime chain, pagination, idempotency, event hooks; fewer knowledge lookups
- **Safety first** — `dryRun` preview, blast-radius circuit breaker (>1000 rows forces a token),
  one-shot confirmation token, `confirmWrite` hard gate for external writes
- **Bilingual documentation** — English and 简体中文 README, cross-linked
- **Docs as tests** — `tools/manifest.json` is generated from the server; CI fails if a documented
  tool does not exist, a link is broken, or a credential leaks

### Changed

- `strategy.get` defaults to `sections=basic`; pass `sections=source|target|all` for full metadata
  (a single full payload is ~40 KB)
- `strategy.dispatchSource` / `dispatchTarget` work on **stopped** strategies and return
  `mode=debug` + `jobId`; pass `requireRunning=true` for the old behaviour
- Destructive tools always return `precheck`; an impact above `MCP_DESTRUCTIVE_MAX_ROWS`
  (default 1000) requires a token **even for `trust=full`**
- A supplied `confirmationToken` is always validated and consumed; replay returns
  `confirmation_token_invalid`
- Debug breadcrumbs are logged as `debug` instead of `fatal`; `dbInfo` exposes `log.debug`
  and `last_run`
- `script.create` / `script.write` run `php -l` before persisting and return
  `file_written` / `syntax_ok`

### Verification

- `scripts/validate_skill.py` — 11 checks (structure, frontmatter, manifest↔docs, links, i18n, secrets)
- `scripts/smoke_test.py` — 8 checks against a read-only tenant (46 tools visible)
- Real debug session recorded in `examples/session-source-debug.md`
- Server-side unit suite: 274 tests / 1318 assertions

### Upgrade notes

- Older clients expecting full metadata from `strategy.get` must pass `sections`
- Anything relying on `strategy_not_running` for stopped strategies should pass `requireRunning=true`
- Tool count changed 39 → 46; refresh `tools/manifest.json` or re-read `meta.capabilities`
